# CueSplice

视频中间删了几段，原字幕从后半段开始全部错位？CueSplice 根据原视频的删除时间段，重新计算 SRT / WebVTT 字幕时间。

**[在线使用](https://yougan001.github.io/cuesplice/)** · [English](README.md)

不是把所有字幕统一提前几秒。每个删除区间都会影响后续时间；跨过剪切点的字幕会裁短或拆分，完全落在删除区间内的字幕会移除。

## 怎么用

1. 导入原始 `.srt` / `.vtt` 字幕，也可以直接粘贴。
2. 填写从**原视频**删掉的时间段，或者导入两列 CSV。
3. 点击 Apply cuts，检查每条字幕的变化，下载字幕和明细 JSON。

例如：

```text
00:00:08.000 --> 00:00:12.500
00:00:24.000 --> 00:00:27.000
```

时间重叠的区间会自动合并，不会重复扣除。时间计算使用整数毫秒。

## 特别注意

拆分和裁短只处理时间，不会判断删掉了哪些台词。原文字会保留，导出前请人工检查标为 Split、Trimmed 的条目。删除区间必须来自原视频，不能混用剪完以后显示的时间。

支持 UTF-8 SRT、独立 WebVTT、多行字幕和 WebVTT 排版参数。暂不支持变速、帧号 EDL、ASS/SSA、逐字卡拉 OK 时间戳和外部时间映射。

文件在浏览器本地处理，不上传字幕或视频，不需要注册。单个字幕文件上限 2 MB，最多 20,000 条字幕和 500 个删除区间。

核心模块不依赖页面框架，也可以直接在 Node.js 中调用。12 项测试覆盖边界时刻、重叠删除区间、毫秒精度、文本保留和异常输入；另有真实浏览器检查，见[测试记录](docs/testing.md)。
